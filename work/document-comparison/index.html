01 The problem

Output QC without two printouts and a highlighter.

Output QC meant opening two versions of a table, listing or figure, often one in Word and one in PDF, and comparing them by eye or with paid PDF software.

02 Why existing approaches fell short

What the old workflow couldn't do.

Generic text-diff tools ignore table structure and figures, and PDF comparison tools compare page layout rather than clinical content, so they flag reflowed lines as changes and miss a moved cell.

05 Difficult engineering decisions

Decisions, trade-offs and how quality was assured.

Decisions & trade-offs
  • Normalise content before comparing. Word and PDF versions can be compared directly. Trade-off: pure layout differences are ignored on purpose.
  • Match table cells by row and column labels. A changed count is reported where it sits, even if the table reflows. Trade-off: it relies on tables having recognisable labels.
  • Pixel-level figure comparison. Any visual change is caught, not just text in the figure. Trade-off: rendering noise needs a tolerance, or trivial differences would be flagged.
Challenges
  • Different formats, same content. A Word draft and its PDF lay out differently, so content is normalised before it is compared.
  • Tables that reflow. Cells are matched by their row and column labels, so a changed count is reported where it sits.
  • Figures. Images are compared pixel by pixel and the changed region is outlined.

What it does

Output QC without printing two copies and reaching for a highlighter.

01 Preview

Open documents in the browser

DOCX, DOC, TXT and PDF open directly in the app. No Word or Acrobat needed.

02 Text

Side-by-side diff

Two versions side by side with additions, deletions and edits highlighted down to the word, across formats: a Word draft against its PDF, or one run against the next.

03 Tables

Table-aware comparison

Clinical output tables are compared cell by cell, not as running text, so a changed count or percentage is pinned to its row and column instead of lost in a reflowed line.

04 Figures

Image diff

Figures and embedded images are compared pixel by pixel, with the changed regions highlighted.

05 Export

Diff report

The comparison downloads as a report to file alongside the outputs it checked.

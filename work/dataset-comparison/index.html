01 The problem

One answer to the question every data refresh raises.

Each data refresh raised the same question, what changed, and it was answered by writing one-off comparison code for each dataset and reading the output.

02 Why existing approaches fell short

What the old workflow couldn't do.

Generic diff tools compare files line by line, so a re-sorted dataset looks completely changed. Ad-hoc compare scripts have to be rewritten for each dataset, and labels and lengths are easy to leave unchecked.

05 Difficult engineering decisions

Decisions, trade-offs and how quality was assured.

Decisions & trade-offs
  • Match on keys, not row order. Sorting or inserted rows don't produce false differences. Trade-off: the user has to choose keys, so their uniqueness is checked first.
  • Compare metadata as well as values. Truncated lengths and label drift surface before submission. Trade-off: format-only changes appear too, so attribute differences are listed separately.
Challenges
  • Keys that aren't keys. Duplicate keys are caught before anything is compared, with a count for each version.
  • Format differences. Labels, types and lengths are compared as well as values, so a truncated variable surfaces before submission.
Validation

An internal tool, validated for use by the biostatistics team that uses it.

What it does

Answers the question every data refresh raises.

01 Read

The formats clinical data arrives in

SAS datasets, XPT transport files, CSV and Excel, in any combination. Compare a SAS dataset with its XPT export, or last month's cut with this month's.

02 Match

Record-level, by key variables

Rows are matched on the keys you choose, such as USUBJID, PARAMCD and AVISIT, not on row order. Added, removed and changed records are flagged, and every changed value shows its old and new value side by side. Keys that don't identify a row uniquely are caught before the comparison runs.

03 Metadata

Variable attributes

Labels, types and lengths are compared as well as values, so a truncated length or a changed label is found before it reaches a submission.

04 Report

Summary and export

A summary of what changed, by record and by variable, with a downloadable report to attach to a QC record.

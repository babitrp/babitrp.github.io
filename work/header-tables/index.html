What it does

A table that answers questions before you scroll.

01 Headers

Statistics where the reader already is

Column headers carry statistical metadata: histograms and summary statistics for numeric columns, level shares for categorical ones, missing counts for both. The summary sits above the data it describes.

02 Filter

Filter from the summary itself

Clicking a bar or a segment filters the table, and every header recomputes for the rows that remain, so a reviewer can follow a question from column to column without leaving the table.

03 Compare

Split by group

Header statistics can be split by a grouping variable such as treatment arm, turning each header into a small comparison.

04 Reuse

Built as a component

Packaged as an htmlwidget on top of reactable, with statistics computed through analysis results datasets (cards / ARD), so the same summaries can feed tables elsewhere.

A reusable widget, not a one-off view.
